# UVA-QA-Software-Tester-Demo
This is quick demo project demonstrating of trying out Postman and Jira
Discloser: I used Claude to facilitate learning these processes

## API Testing with Postman
- Built a collection of 6 requests against the JSONPlaceholder API
  (GET, POST, PUT, DELETE, plus a negative 404 test)
- Wrote assertions for status codes, response structure, and response time
- Debugged my own failing tests (incorrect request body format, wrong
  assertions for array vs. object responses)
- Ran the collection with the Collection Runner: [result]

File: `postman/JSONPlaceholder-API-Tests.postman_collection.json`

## Defect Tracking with Jira
- Logged bug reports with environment, repro steps, expected/actual results
- Moved a bug through the full lifecycle: To Do → In Progress → In Review → Done,
  with diagnosis and verification comments

Screenshots in `jira/`.
